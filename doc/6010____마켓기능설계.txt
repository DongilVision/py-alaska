  1. 개요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1.1 현재 상황
  ─────────────

  재사용 가능한 블록(카메라, 이미지 저장, 조이스틱 등)이 example/에
  산재해 있지만, 다른 프로젝트에서 가져다 쓸 체계가 없다.

      현재: example/ex130a_camera/ 통째 복사 → import 경로 수정
            → config 수정 → 의존성 수동 확인 → 원본 업데이트 시 수동 동기화

  1.2 목표
  ────────

      alaska market install imi_camera
      → config.json에 "@market": "imi_camera" 추가
      → 소스 + 의존성 + SmStruct 자동 도착, 업데이트 가능

  1.3 핵심 원칙
  ─────────────

  ① Git 기반: 별도 서버 없이 Git 저장소가 곧 마켓
  ② 블록 단위: Task + Config + Struct 묶음
  ③ 소스 투명: 가져온 코드가 소스로 존재 (수정 가능)
  ④ 인덱스 분리: 메타정보와 소스를 분리 관리

  2. 블록(Block) 정의
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  2.1 블록 구조
  ─────────────

      imi_camera/
      ├── block.yaml              ← 블록 매니페스트 (필수)
      ├── task_cam_driver.py      ← Task 소스
      ├── task_viewer.py          ← (선택) 추가 Task
      ├── structs.py              ← (선택) SmStruct 정의
      └── README.md               ← (선택) 사용법 문서

  2.2 block.yaml 매니페스트
  ─────────────────────────

      block:
        name: imi_camera
        version: "1.0.0"
        description: "IMI 산업용 카메라 드라이버 (GigE Vision)"
        author: "dongil-vision"
        alaska_version: ">=2.6"

      tasks:
        - class: imi_cam_dp
          mode: process
          module: task_cam_driver

        - class: ImiCameraView
          mode: thread
          module: task_viewer

      required:
        cam_id:
          type: str
          doc: "카메라 MAC 주소 (필수)"
        trigger_source:
          type: str
          default: "software"
          choices: ["software", "hardware"]

      structs:
        FrameInfo:
          module: structs
          fields:
            - sm_index: uint32
            - trigger_mode: bool8
            - time: int64
            - rx_count: uint32
            - drop_count: uint32
            - uptime: uint64

      signals:
        - camera.connected
        - camera.disconnected
        - camera.received:
            struct: FrameInfo

      depends:
        blocks: []
        python: [numpy>=1.21]
        system: [NeptuneC_MD_VC141.dll]

      source:
        git: "https://github.com/dongil-vision/alaska-blocks.git"
        path: "blocks/imi_camera"
        tag: "v1.0.0"

  3. Git 연동 — 블록 가져오기

  3.1 마켓 저장소 구조
  ────────────────────

      alaska-blocks.git
      ├── index.yaml               ← 마켓 인덱스
      ├── blocks/
      │   ├── imi_camera/
      │   ├── image_writer/
      │   ├── joystick/
      │   └── smblock_viewer/
      └── README.md

  3.2 설치 흐름
  ─────────────

      alaska market install imi_camera
          │
          ├─ ① index.yaml에서 imi_camera 검색
          │     → git repo URL + path + tag 확인
          │
          ├─ ② Git sparse checkout (해당 블록만)
          │     git clone --filter=blob:none --sparse <repo>
          │     git sparse-checkout set blocks/imi_camera
          │     git checkout tags/v1.0.0
          │
          ├─ ③ 로컬 배치
          │     → alaska_blocks/imi_camera/ 에 복사
          │
          ├─ ④ 의존성 확인
          │     python → pip install 안내
          │     blocks → 재귀 install
          │     system → DLL 존재 여부 경고
          │
          └─ ⑤ alaska_blocks.lock 기록

  3.3 Git 전략
  ────────────

  ┌───────────────────┬────────────────────────┬──────────────┐
  │ 방식              │ 특징                    │ 적합도       │
  ├───────────────────┼────────────────────────┼──────────────┤
  │ sparse checkout   │ 필요 블록만, 최소 I/O   │ ★ 기본       │
  │ archive download  │ Git 불필요, 가장 빠름   │ ○ fallback  │
  │ git submodule     │ 표준이나 전체 복제 필수  │ △           │
  └───────────────────┴────────────────────────┴──────────────┘

  4. 인덱스 (Market Index)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  4.1 역할
  ────────

  인덱스는 마켓 저장소의 모든 블록 메타정보 카탈로그이다.
  소스 다운로드 없이 검색, 버전 조회, 의존성 확인이 가능하다.

  4.2 index.yaml
  ──────────────

      market:
        name: "alaska-official"
        url: "https://github.com/dongil-vision/alaska-blocks.git"
        updated: "2026-03-06"

      blocks:
        imi_camera:
          latest: "1.0.0"
          description: "IMI 산업용 카메라 드라이버"
          tags: [camera, gige, hardware]
          tasks: [imi_cam_dp, ImiCameraView]
          required: [cam_id]
          depends_python: [numpy]
          versions:
            "1.0.0":
              tag: "v1.0.0"
              path: "blocks/imi_camera"
              alaska: ">=2.6"

        image_writer:
          latest: "1.0.0"
          description: "프레임 이미지 파일 저장기"
          tags: [image, writer, smblock]
          tasks: [ImageWriterTask]
          required: [save_path]
          depends_python: [opencv-python]
          versions:
            "1.0.0":
              tag: "v1.0.0"
              path: "blocks/image_writer"
              alaska: ">=2.6"

  4.3 인덱스 유지 관리
  ────────────────────

  (A) 수동: 블록 저자가 index.yaml에 직접 등록 (소규모 팀)

  (B) CI 자동: push 시 blocks/*/block.yaml 스캔 → index.yaml 재생성

      # .github/workflows/update-index.yml
      on:
        push:
          paths: ['blocks/*/block.yaml']
      jobs:
        update-index:
          runs-on: ubuntu-latest
          steps:
            - uses: actions/checkout@v4
            - run: python scripts/build_index.py
            - run: git add index.yaml && git commit -m "Update index"

  (C) 로컬 캐시:

      ~/.alaska/market/
      ├── cache/alaska-official/index.yaml
      └── sources.yaml                      ← 등록된 마켓 목록

  4.4 다중 마켓 소스
  ──────────────────

      # ~/.alaska/market/sources.yaml
      sources:
        - name: company-internal
          url: "https://gitlab.company.com/alaska-blocks.git"
          priority: 0            # 사내 우선

        - name: alaska-official
          url: "https://github.com/dongil-vision/alaska-blocks.git"

  5. 사용법 (GUI 기반)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  마켓의 주 인터페이스는 MarketBrowser GUI(§9)이다.
  모든 조작(검색, 설치, 업데이트, 제거, 등록)은 GUI에서 수행한다.

  5.1 시나리오: 검색 → 설치 → 사용
  ─────────────────────────────────

  ① MarketBrowser 열기
     - AlaskaApp 메뉴 → 마켓 브라우저
     - 또는 독립 실행: python -m alaska.market_browser

  ② 검색 탭에서 블록 찾기 (§9.2)
     - 검색창에 "camera" 입력 → 블록 카드 목록 표시
     - 분류 드롭다운으로 태그 필터링 (camera / image / io / ...)

      ┌─ imi_camera ──────────────── v1.0.0 ─────── [Install] ┐
      │  IMI 산업용 카메라 드라이버 (GigE Vision)               │
      │  tags: camera, gige, hardware                          │
      └────────────────────────────────────────────────────────┘

  ③ [Install] 클릭 → 상세 다이얼로그 (§9.3)
     - block.yaml 전체 정보 확인 (Tasks, Signals, SmStruct, 의존성)
     - 버전 드롭다운에서 원하는 버전 선택
     - [Install v1.0.0] 클릭

  ④ 다운로드 진행 (§9.4)
     - 5단계 프로그레스 표시 (인덱스 → Git checkout → 배치 → 의존성 → lockfile)
     - 완료 시 config.json 자동 추가 옵션 제공

      ┌─ 설치 완료 ────────────────────────────────────────────┐
      │  ✓ imi_camera v1.0.0 설치됨                            │
      │    → alaska_blocks/imi_camera/                          │
      │  config.json 자동 추가:                                 │
      │    □ Task 이름: [cam1__________]  [config에 추가]       │
      └────────────────────────────────────────────────────────┘

  ⑤ config.json 확인
     - "config에 추가" 선택 시 자동 삽입됨
     - 수동 편집도 가능:

      {
        "task_config": {
          "cam_top/imi_cam_dp": {
            "@market": "imi_camera",
            "cam_id": "AA:BB:CC:00:11:22",
            "trigger_source": "hardware"
          }
        }
      }

  5.2 설치된 블록 관리 (§9.5)
  ───────────────────────────

  설치됨 탭에서 lockfile 기반 목록 확인:
  - [Update ↑]   : 새 버전 존재 시 원클릭 업데이트
  - [Update All]  : 전체 블록 일괄 업데이트
  - [Remove]      : 블록 삭제 (확인 다이얼로그)
  - [Open Folder] : alaska_blocks/<블록>/ 탐색기 열기

  5.3 블록 등록 (§9.7)
  ─────────────────────

  블록 등록 다이얼로그에서:
  ① [Browse...] → 블록 폴더 선택
  ② 자동 검증 (block.yaml, Task, SmStruct, 의존성)
  ③ 마켓 소스 선택 + 버전 태그 입력
  ④ [Publish] → Git commit + tag + push

  5.4 config.json — @market 사용
  ──────────────────────────────

      {
        "task_config": {
          "cam_top/imi_cam_dp": {
            "@market": "imi_camera",
            "cam_id": "AA:BB:CC:00:11:22",
            "trigger_source": "hardware"
          },
          "cam_bottom/imi_cam_dp": {
            "@market": "imi_camera",
            "cam_id": "AA:BB:CC:00:11:33",
            "trigger_source": "software"
          },
          "saver/ImageWriterTask": {
            "@market": "image_writer",
            "save_path": "D:/images/"
          },
          "inspector/InspectionTask": {
            "@import": "tasks"
          }
        }
      }

  @market과 기존 @import가 자연스럽게 공존한다.
  같은 블록의 Task를 여러 인스턴스로 생성 가능 (cam_top, cam_bottom).
  GUI 설치 시 "config에 추가" 옵션으로 위 항목이 자동 생성된다.

  5.5 @market vs @import
  ──────────────────────

  ┌──────────────┬─────────────────────┬─────────────────────┐
  │ 항목         │ @import (기존)       │ @market (신규)       │
  ├──────────────┼─────────────────────┼─────────────────────┤
  │ 모듈 위치     │ 사용자 직접 지정     │ alaska_blocks/ 자동 │
  │ 의존성 관리   │ 수동                │ block.yaml 자동     │
  │ 버전 관리     │ 없음                │ lockfile + tag      │
  │ 업데이트      │ 수동 복사           │ GUI 원클릭          │
  │ 강제속성 검증 │ 없음                │ required 자동 검증  │
  │ SmStruct     │ 수동 import         │ structs 자동 로드   │
  │ 설치 방법     │ 수동 파일 배치      │ GUI 검색 → Install  │
  └──────────────┴─────────────────────┴─────────────────────┘

  5.6 @market 처리 흐름 (TaskManager 내부)
  ────────────────────────────────────────

      config.json 로드 → task_config 순회
          │
          ├─ "@import" → 기존 __import__() 호출
          │
          └─ "@market" 발견
              ├─ ① block.yaml 파싱
              ├─ ② REQUIRED_PROPERTY 검증 → TaskConfigError
              ├─ ③ SmStruct 클래스 로드
              ├─ ④ __import__(block_module) → _task_registry 등록
              └─ ⑤ Signal-Struct 바인딩
              → TaskInfo 생성 (기존 흐름 합류)

  6. 블록 작성 가이드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  6.1 새 블록 만들기 (예: 온습도 센서)
  ─────────────────────────────────────

      # task_sensor.py
      @task(name="my_sensor", mode="process")
      class MySensorTask:
          REQUIRED_PROPERTY = {
              "port:str": {"doc": "시리얼 포트"},
              "baudrate:int": {"doc": "통신 속도", "default": 115200},
          }
          DEVICE_PROPERTY = {
              "is_connect:bool=false": {},
              "interval:float=1.0": {"setter": "_hw_set_interval"},
          }

      # structs.py
      class SensorData(SmStruct):
          _fields_ = [
              ('temperature', 'float32'),
              ('humidity',    'float32'),
              ('timestamp',   'int64'),
          ]

      # block.yaml
      block:
        name: my_sensor
        version: "1.0.0"
        description: "온습도 센서 드라이버"
      tasks:
        - class: MySensorTask
          module: task_sensor
      required:
        port: {type: str, doc: "시리얼 포트"}
      structs:
        SensorData: {module: structs}
      depends:
        python: [pyserial>=3.5]

  6.2 발행 검증

      $ alaska market publish ./my_sensor
      ✓ block.yaml 유효
      ✓ Task: MySensorTask
      ✓ SmStruct: SensorData (12B)
      ✓ 의존성 명시 확인
      → Git 저장소에 push

  6.3 검증 규칙
  ─────────────

  ┌──┬──────────────────────────────────┬────────────────────┐
  │# │ 검증 항목                         │ 실패 시             │
  ├──┼──────────────────────────────────┼────────────────────┤
  │1 │ block.yaml 존재 + 스키마 유효     │ ERROR              │
  │2 │ name이 [a-z_] 패턴               │ ERROR              │
  │3 │ Task 클래스가 module에 존재       │ ERROR              │
  │4 │ SmStruct 타입 유효               │ ERROR              │

  9.8 MarketBrowser Task 설계
  ───────────────────────────

      @task(name="market_browser", mode="thread")
      class MarketBrowser(QWidget):
          """마켓 브라우저 GUI Task.

          signal_subscribe 불필요 — 자체 UI 이벤트 기반.
          AlaskaApp.run() 또는 standalone 모드 모두 지원.
          """

          # Qt Signals (UI 갱신용)
          search_done      = Signal(list)     # 검색 결과 목록
          install_progress = Signal(int, str) # step, message
          install_done     = Signal(dict)     # 결과 요약

          def __init__(self):
              super().__init__()
              self._market_api = None   # MarketAPI 인스턴스 (§9.9)
              self._setup_ui()

          def run(self):
              """Task 시작 — MarketAPI 초기화 + 인덱스 로드."""
              self._market_api = MarketAPI()
              self._market_api.refresh_index()

          # ── UI 구성 ──────────────────────────────────
          def _setup_ui(self):
              tabs = QTabWidget()
              tabs.addTab(self._create_search_tab(),    "검색")
              tabs.addTab(self._create_installed_tab(),  "설치됨")
              tabs.addTab(self._create_sources_tab(),    "소스 관리")
              layout = QVBoxLayout(self)
              layout.addWidget(tabs)

          # ── 백그라운드 작업 ──────────────────────────
          # Git clone / checkout 등 I/O 작업은 ThreadPoolExecutor에서 실행
          # → install_progress Signal로 UI 업데이트
          # → @ui_thread로 위젯 갱신

          @ui_thread
          def _on_search_result(self, blocks):
              """검색 완료 → 카드 리스트 갱신."""
              ...

          @ui_thread
          def _on_install_step(self, step, message):
              """설치 단계 진행 → 프로그레스 갱신."""
              ...


  9.9 MarketAPI 내부 클래스
  ─────────────────────────

  GUI와 CLI가 공유하는 핵심 로직 레이어.

      class MarketAPI:
          """마켓 조작 핵심 API (GUI/CLI 공용).

          모든 I/O는 동기 호출 — GUI에서는 executor에서 실행.
          """

          def refresh_index(self) -> None:
              """모든 소스의 index.yaml 갱신."""

          def search(self, keyword: str, tag: str = None) -> list[BlockInfo]:
              """키워드 + 태그 기반 블록 검색."""

          def get_detail(self, name: str, version: str = None) -> BlockDetail:
              """블록 상세 정보 (block.yaml 전체 파싱)."""

          def install(self, name: str, version: str = None,
                      on_progress: Callable = None) -> InstallResult:
              """블록 설치 (§3.2 흐름 실행)."""

          def update(self, name: str = None) -> list[UpdateResult]:
              """블록 업데이트 (전체 또는 개별)."""

          def remove(self, name: str) -> bool:
              """블록 제거 + lockfile 정리."""

          def list_installed(self) -> list[InstalledBlock]:
              """설치된 블록 목록 (lockfile 기반)."""

          def validate_block(self, path: str) -> list[ValidationItem]:
              """블록 검증 (§6.3 규칙 적용)."""

          def publish(self, path: str, source: str,
                      version_tag: str) -> PublishResult:
              """블록 등록 (검증 → 복사 → index 갱신 → push)."""

          def get_sources(self) -> list[MarketSource]:
              """등록된 마켓 소스 목록."""

          def add_source(self, url: str, name: str, priority: int) -> None:
              """마켓 소스 추가."""
