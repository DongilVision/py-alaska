  │                       │ fps: float                                    │
  ├───────────────────────┼───────────────────────────────────────────────┤
  │ camera.disconnected   │ source: str                                   │
  │                       │ reason: str                                   │
  │                       │ captured: int                                 │
  │                       │ dropped: int                                  │
  ├───────────────────────┼───────────────────────────────────────────────┤
  │ camera.received       │ sm_index: int        (SmBlock 슬롯)           │
  │                       │ trigger_mode: bool                            │
  │                       │ rx_sequence: int                              │
  │                       │ rx_timestamp: float  (time.time() Unix)       │
  │                       │ rx_count: int                                 │
  │                       │ rx_drop: int                                  │
  └───────────────────────┴───────────────────────────────────────────────┘

  mode="sim" 으로 소비자가 시뮬레이션 모드를 구분할 수 있으나,
  하류 로직은 이 값을 무시해도 된다.

  2.2 DEVICE_PROPERTY — 동일 구조
  ────────────────────────────────

  DEVICE_PROPERTY = {
      "is_connect:bool=false": {},
      "fps:float=30.0":      {"setter": "_sim_set_fps"},
      "exposure:int=15000":  {},               # HW 없으므로 캐시만
      "trigger_mode:bool=false": {"setter": "_sim_set_trigger"},
      "@resync": {
          "open":  "_noop",
          "close": "_noop",
          "condition": {"Eq": ["is_connect", True]},
          "order": ["trigger_mode", "fps", "exposure"]
      }
  }

  setter 동작:
  - _sim_set_fps(val)     → self._frame_interval = 1.0 / val (재생 속도 변경)
  - _sim_set_trigger(val) → True: 자동 재생 중지, one_shot()으로 수동 전진

  5.1 실제 카메라의 Trigger 동작
  ──────────────────────────────

  실제 카메라(imi_cam_dp)에서 trigger는 2개의 독립 속성으로 동작한다:

      ┌──────────────────┬──────────────────────────────────────────────┐
      │ 속성              │ 역할                                        │
      ├──────────────────┼──────────────────────────────────────────────┤
      │ trigger_mode     │ DEVICE_PROPERTY, bool                       │
      │                  │ False: 연속 촬영 (HW가 fps대로 콜백)        │
      │                  │ True:  트리거 대기 (외부 신호 시에만 촬영)   │
      ├──────────────────┼──────────────────────────────────────────────┤
      │ trigger_source   │ config.json 일반 속성 (DEVICE_PROPERTY 아님)│
      │                  │ "software": one_shot() → ntcRunSWTrigger()  │
      │                  │ "hardware": 외부 HW 라인1 신호 대기          │
      └──────────────────┴──────────────────────────────────────────────┘

  HW 흐름:

      trigger_mode=False (기본):
      ┌─ 카메라 HW ──────────────────────────────────────────────────┐
      │  ntcSetAcquisition(True) → 카메라가 fps 간격으로 자동 전송   │
      │  RecvFrameCallBack()이 HW 스레드에서 직접 호출됨              │
      │  run() 루프는 cmd queue 폴링만 (프레임 처리 없음)            │
      └──────────────────────────────────────────────────────────────┘

      trigger_mode=True:
      ┌─ 카메라 HW ──────────────────────────────────────────────────┐
      │  ntcSetTrigger(OnOff=True, Source=SW/HW)                     │
      │  카메라는 대기 상태 → 프레임 전송 안 함                       │
      │                                                               │
      │  trigger_source="software":                                   │
      │    one_shot() → ntcRunSWTrigger() → 1프레임만 전송            │
      │    → RecvFrameCallBack() 1회 호출                             │
      │                                                               │
      │  trigger_source="hardware":                                   │
      │    외부 라인1 신호 → 1프레임 전송                              │
      │    → RecvFrameCallBack() 1회 호출                             │
      └──────────────────────────────────────────────────────────────┘

  핵심: 실제 카메라에서 프레임 수신은 항상 RecvFrameCallBack() 경유.
  trigger_mode는 "콜백이 호출되는 조건"을 바꿀 뿐, 콜백 내부 로직은 동일.

  one_shot() 가드 조건 (task_cam_driver.py:448-457):

      def one_shot(self):
          if not self.is_connect:
              self.print("WARN one_shot called but not connected")
              return
          if self.trigger_source != "software":
              self.print("WARN one_shot: trigger_source is not 'software'")
              return
          ntcRunSWTrigger(self.handle)

  5.2 SimCam에서의 Trigger 매핑
  ─────────────────────────────

  SimCam은 HW 콜백이 없으므로, trigger 동작을 run() 루프에서 직접 구현한다.

  ┌───────────────────────────┬────────────────────────────────────────┐
  │ 실제 카메라                │ SimCam                                │
  ├───────────────────────────┼────────────────────────────────────────┤
  │ trigger_mode=False        │ replay_mode 기준 자동 재생             │
  │ HW가 fps 간격으로 콜백    │ sleep(1/fps)로 간격 제어               │
  ├───────────────────────────┼────────────────────────────────────────┤
  │ trigger_mode=True         │ 재생 일시정지                          │
  │ HW가 대기 상태            │ _trigger_event.wait() 블로킹           │
  ├───────────────────────────┼────────────────────────────────────────┤
  │ one_shot()                │ _trigger_event.set()                   │
  │ ntcRunSWTrigger()         │ → 1프레임 읽기 → emit → 다시 대기     │
  ├───────────────────────────┼────────────────────────────────────────┤
  │ trigger_source="hardware" │ SimCam에서는 무시                      │
  │ (외부 라인 신호)          │ trigger_source 속성은 수용하되 동작 무관│
  ├───────────────────────────┼────────────────────────────────────────┤
  │ _hw_set_trigger(enabled)  │ _sim_set_trigger(enabled)             │
  │ ntcSetTrigger(OnOff)      │ _paused = enabled                    │
  │ + @resync session         │ @resync open/close = _noop            │
  └───────────────────────────┴────────────────────────────────────────┘

  5.3 trigger_mode와 replay_mode 상호작용
  ────────────────────────────────────────

  trigger_mode는 런타임에 RMI로 변경 가능하다.
  replay_mode와의 조합을 명확히 정의한다:

  ┌──────────────┬──────────────────┬──────────────────────────────────┐
  │ replay_mode  │ trigger_mode     │ 동작                             │
  ├──────────────┼──────────────────┼──────────────────────────────────┤
  │ realtime     │ False (기본)     │ 1/fps 간격 자동 재생             │
  │ realtime     │ True  (변경)     │ 자동 재생 중지 → one_shot 대기   │
  │ realtime     │ True→False      │ 중지 위치에서 자동 재생 재개     │
  ├──────────────┼──────────────────┼──────────────────────────────────┤
  │ original     │ False            │ 원본 타이밍 자동 재생            │
  │ original     │ True             │ 자동 재생 중지 → one_shot 대기   │
  ├──────────────┼──────────────────┼──────────────────────────────────┤
  │ fast         │ False            │ 최대 속도 연속 재생              │
  │ fast         │ True             │ 자동 재생 중지 → one_shot 대기   │
  ├──────────────┼──────────────────┼──────────────────────────────────┤
  │ step         │ (항상 True)      │ 시작부터 one_shot() 대기         │
  │              │                  │ trigger_mode=False 무시           │
  └──────────────┴──────────────────┴──────────────────────────────────┘

  규칙 요약:
  - trigger_mode=True → 어떤 replay_mode든 자동 재생 중지
  - trigger_mode=False → replay_mode 기준 자동 재생 (step 제외)
  - step 모드는 trigger_mode 강제 True (설정 변경 무시)

  5.4 SimCam Trigger 구현 상세
  ────────────────────────────

      class SimCam:
          def __init__(self):
              self._trigger_event = None    # threading.Event (run에서 생성)
              self._paused = False           # trigger_mode 반영
              self.trigger_source = "software"  # 호환용 (동작 무관)

          # ── DEVICE_PROPERTY setter ──────────────────
          def _sim_set_trigger(self, enabled):
              """trigger_mode 변경 처리"""
              self._paused = enabled
              if not enabled and self._trigger_event:
                  # trigger 해제 → 자동 재생 재개
                  self._trigger_event.set()
              self.print(f"trigger_mode={'ON (paused)' if enabled else 'OFF (playing)'}")

          # ── one_shot (실제 카메라와 동일 인터페이스) ──
          def one_shot(self):
              """RMI: trigger 모드에서 1프레임 전진

              실제 카메라의 one_shot()과 동일한 가드 조건:
              - is_connect 검사
              - trigger_source 검사 (SimCam은 경고만)
              """
              if not self.is_connect:
                  self.print("WARN one_shot called but not connected")
                  return
              if self.trigger_source != "software":
                  self.print(f"WARN one_shot: trigger_source='{self.trigger_source}' "
                             "(SimCam ignores, proceeding)")
              self._trigger_event.set()

          # ── 프레임 루프 내 대기 로직 ────────────────
          def _should_wait_trigger(self):
              """현재 프레임 전에 trigger 대기가 필요한지"""
              if self.replay_mode == "step":
                  return True                    # step 모드: 항상 대기
              return self._paused               # 나머지: trigger_mode 반영

          def _wait_trigger(self):
              """trigger/one_shot 대기 (CPU 0%)

              Returns:
                  bool: True=프레임 전진, False=should_stop
              """
              while not self.runtime.should_stop():
                  if self._trigger_event.wait(timeout=0.5):
                      self._trigger_event.clear()
                      return True
              return False

          if not self._should_wait_trigger():
              self._pace(i, filepath)

  5.6 동적 전환 시나리오
  ──────────────────────

  시나리오 1 — 재생 중 trigger 켜기:

      [realtime 자동 재생 중]
      UI: cam.trigger_mode = True
        → _sim_set_trigger(True)
        → _paused = True
        → 다음 프레임부터 _should_wait_trigger() = True
        → _wait_trigger()에서 블로킹
      [정지 상태]
      UI: cam.one_shot()
        → _trigger_event.set()
        → 1프레임 로드 → emit → 다시 대기
      [1프레임 전진]

  시나리오 2 — trigger 끄기 (재생 재개):

      [정지 상태 — _wait_trigger() 대기 중]
      UI: cam.trigger_mode = False
        → _sim_set_trigger(False)
        → _paused = False
        → _trigger_event.set()        ← 대기 해제 (재개)
        → _should_wait_trigger() = False
        → _pace()로 자동 재생 복귀
      [realtime 자동 재생]

  시나리오 3 — one_shot 연타:

      [trigger_mode=True, 정지 상태]
      UI: cam.one_shot()  (빠르게 10회 호출)
        → _trigger_event.set() 반복
        → event.set()은 이미 set이면 무해
        → 실제로 1프레임만 진행 (clear 후 다시 대기)
        → 2번째 one_shot()은 다음 wait에서 즉시 깨움
        → 결과: 10프레임 순차 전진 (중복 없음)

      주의: one_shot() 간격이 이미지 로딩 시간(~10ms)보다 빠르면
      이벤트가 누적되지 않으므로 일부가 씹힐 수 있다.
      → 대안: 카운터 방식 (§5.7)

  5.7 개선 옵션: one_shot 카운터
  ──────────────────────────────

  threading.Event는 binary flag이므로 연속 one_shot()이 씹힐 수 있다.
  정확한 N프레임 전진이 필요하면 카운터 방식:

      self._shot_count = 0          # one_shot 잔여 횟수
      self._shot_lock = threading.Lock()

      def one_shot(self, count=1):
          """RMI: N프레임 전진 (기본 1)"""
          with self._shot_lock:
              self._shot_count += count
          self._trigger_event.set()

      def _wait_trigger(self):
          while not self.runtime.should_stop():
              if self._trigger_event.wait(timeout=0.5):
                  with self._shot_lock:
                      if self._shot_count > 0:
                          self._shot_count -= 1
                          if self._shot_count == 0:
                              self._trigger_event.clear()
                          return True
                      # trigger_mode 해제로 인한 set
                      if not self._paused:
                          self._trigger_event.clear()
                          return True
          return False

  이점:
  - one_shot(10) → 정확히 10프레임 연속 재생 후 정지
  - one_shot() 연타 → 횟수 누적 (손실 없음)
  - 실제 카메라에는 없는 SimCam 전용 확장 (count 파라미터)

  5.1 구조 개요

      @task(name="sim_cam", mode="process", restart=True,
            DEVICE_PROPERTY={...})
      class SimCam:

          # config.json 주입
          self.replay_path = ""         # 재생 디렉토리 경로
          self.session = ""             # 세션 이름 ("S001", "" = 최신)
          self.replay_mode = "realtime" # realtime | original | fast | step
          self.loop = False             # False | True | int
          self.fps = 30.0               # realtime 모드 재생 fps
          self.start_frame = 0          # 시작 프레임 (0-based)
          self.end_frame = -1           # 끝 프레임 (-1 = 전체)

  5.2 run() 흐름
  ──────────────

      def run(self):
          # 1. 입력 준비
          files = self._scan_session()         # 파일 목록 (정렬)
          if not files:
              self.print("ERROR: no images found")
              return

          self._frame_interval = 1.0 / self.fps
          self.is_connect = True               # → @resync → connected emit

          # 2. 재생 루프
          loop_count = 0
          while not self.runtime.should_stop():
              for i, filepath in enumerate(files):
                  if self.runtime.should_stop():
                      break

                  # step 모드: trigger 대기
                  if self.trigger_mode:
                      self._wait_trigger()
                      if self.runtime.should_stop():
                          break

                  # 이미지 로드
                  image = cv2.imread(str(filepath), cv2.IMREAD_UNCHANGED)
                  if image is None:
                      self.rx_drop += 1
                      continue

                  # SmBlock 할당
                  index = self.smblock.alloc()
                  if index == -1:
                      self.rx_drop += 1
                      continue

                  # SmBlock에 복사
                  dst = self.smblock.get_buffer(index)
                  try:
                      dst[:] = image
                  except ValueError:
                      self.smblock.mfree(index)
                      self.rx_drop += 1
                      continue

                  # 시그널 발신
                  self.rx_count += 1
                  self.signal.camera.received.emit({
                      "sm_index": index,
                      "trigger_mode": self._cache.get("trigger_mode", False),
                      "rx_sequence": self.rx_count,
                      "rx_timestamp": self._get_timestamp(filepath),
                      "rx_count": self.rx_count,
                      "rx_drop": self.rx_drop,
                  })

                  # 타이밍 제어
                  self._pace(i, filepath)

              # 루프 판정
              loop_count += 1
              if not self._should_loop(loop_count):
                  break

          # 3. 종료
          self.is_connect = False
          self.signal.camera.disconnected.emit({
              "source": self.runtime.name,
              "reason": "end_of_replay",
              "captured": self.rx_count,
              "dropped": self.rx_drop,
          })

  5.3 타이밍 제어 (_pace)
  ───────────────────────

      def _pace(self, frame_idx, filepath):
          """재생 모드별 타이밍"""
          if self.replay_mode == "realtime":
              time.sleep(self._frame_interval)

          elif self.replay_mode == "original":
              if frame_idx > 0:
                  dt = self._get_timestamp(filepath) - self._prev_ts
                  if 0 < dt < 10:       # 비정상 간격 제한 (10초)
                      time.sleep(dt)
              self._prev_ts = self._get_timestamp(filepath)

          elif self.replay_mode == "fast":
              pass                       # sleep 없음, 최대 속도

          elif self.replay_mode == "step":
              pass                       # _wait_trigger에서 이미 대기함

  5.4 타임스탬프 복원
  ───────────────────

      def _get_timestamp(self, filepath):
          """파일명에서 원본 타임스탬프 복원, 실패 시 현재 시각"""
          # img_0001_20260307_143022_123.png
          name = filepath.stem
          parts = name.split("_")
          try:
              date_str = parts[2]        # 20260307
              time_str = parts[3]        # 143022
              ms_str = parts[4]          # 123
              dt = datetime.strptime(f"{date_str}{time_str}", "%Y%m%d%H%M%S")
              return dt.timestamp() + int(ms_str) / 1000.0
          except (IndexError, ValueError):
              return time.time()

  5.5 one_shot (step/trigger 모드)
  ─────────────────────────────────

      def one_shot(self):
          """RMI: step/trigger 모드에서 1프레임 전진"""
          self._trigger_event.set()

      def _wait_trigger(self):
          """트리거 대기 (CPU 0%)"""
          while not self.runtime.should_stop():
              if self._trigger_event.wait(timeout=0.5):
                  self._trigger_event.clear()
                  return

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  10.1 이미지 로딩 비용
  ─────────────────────

  cv2.imread (2048×2448×3 BGR, PNG):  ~5-15ms
  SmBlock 복사 (memcpy 15MB):         ~2-3ms
  합계:                                ~7-18ms → 최대 ~55-140 fps

  fast 모드에서 디스크 I/O가 병목.
  고속 재생이 필요하면 사전 로딩(preload) 적용.

  10.2 Preload 전략 (선택)
  ────────────────────────

  별도 스레드에서 N프레임 선행 읽기:

      _preload_queue = queue.Queue(maxsize=16)

      def _preload_thread(self):
          for filepath in self._files:
              image = cv2.imread(str(filepath), cv2.IMREAD_UNCHANGED)
              self._preload_queue.put((filepath, image))  # 블로킹

      def _next_frame(self):
          return self._preload_queue.get(timeout=1.0)

  preload=16 시:
  - 메모리: 16 × 15MB = ~240MB 추가
  - 효과: 디스크 I/O 대기 제거, CPU만 소모
  - fast 모드에서 SmBlock alloc 속도가 병목으로 전환

  10.3 타이밍 정확도
  ──────────────────

  realtime 모드: time.sleep() 기반이므로 ±1ms 오차.
  original 모드: 파일명 파싱 정밀도는 1ms.
  보정: sleep 전 drift 계산으로 누적 오차 방지.

      elapsed = time.perf_counter() - self._start_time
      expected = frame_idx * self._frame_interval
      drift = expected - elapsed
      if drift > 0.001:
          time.sleep(drift)

      pytest에서 SimCam 구동 → 알려진 이미지 입력 → 기대 결과 검증.

      결정적(deterministic) 입력 → 재현 가능한 테스트.

      replay_mode: "original" → 원본 타이밍으로 재현.
      step 모드로 문제 프레임 전후 분석.

  시나리오 D — 성능 벤치마크:

      replay_mode: "fast" → 하류 파이프라인 최대 처리량 측정.
      SmBlock 슬롯 고갈 시점 = 파이프라인 병목 지점.

  시나리오 E — 데모/교육:

      실제 장비 없이 시스템 전체 흐름 시연.
      replay_mode: "realtime", loop: true, fps: 10

  15.4 프레임 렌더링 구현
  ──────────────────────

      import cv2
      import numpy as np
      import math
      from datetime import datetime, timedelta

      def _render_frame(frame_num, total, width, height, channels,
                        timestamp, fps, bg_color, text_color):
          """단일 프레임 렌더링"""

          # 1. 배경 생성
          if channels == 3:
              img = np.full((height, width, 3), bg_color, dtype=np.uint8)
          else:
              img = np.full((height, width), bg_color[0], dtype=np.uint8)

          # 2. 프레임 번호 (좌상단)
          text = f"FRAME: {frame_num:04d} / {total:04d}"
          font = cv2.FONT_HERSHEY_SIMPLEX
          scale = min(width, height) / 800.0    # 해상도 비례 스케일
          cv2.putText(img, text, (50, int(80*scale)),
                      font, scale * 1.5, text_color, 3)

          # 3. 타임스탬프
          dt = datetime.fromtimestamp(timestamp)
          time_text = f"TIME: {dt.strftime('%H:%M:%S')}.{dt.microsecond//1000:03d}"
          cv2.putText(img, time_text, (50, int(160*scale)),
                      font, scale, text_color, 2)

          # 4. 아날로그 시계 (화면 중앙)
          cx, cy = width // 2, height // 2
          radius = int(min(width, height) * 0.2)
          _draw_clock(img, cx, cy, radius, frame_num, total,
                      timestamp, text_color)

          # 5. 하단 정보 바
          info = f"SimCam Test | {width}x{height} | {fps:.0f}fps"
          cv2.putText(img, info, (50, height - int(50*scale)),
                      font, scale * 0.7, text_color, 2)

          return img

      def _draw_clock(img, cx, cy, radius, frame_num, total, timestamp, color):
          """아날로그 시계 — 원형 + 눈금 + 초침 화살표"""

          # 원형 외곽
          cv2.circle(img, (cx, cy), radius, color, 2)

          # 12시/3시/6시/9시 눈금
          for hour, label in [(0, "12"), (3, "3"), (6, "6"), (9, "9")]:
              angle = math.radians(hour * 30 - 90)
              tx = int(cx + (radius + 20) * math.cos(angle))
              ty = int(cy + (radius + 20) * math.sin(angle))
              cv2.putText(img, label, (tx - 10, ty + 8),
                          cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2)

          # 분침 — 프레임 진행율 기반 (0~total → 0~360°)
          progress = frame_num / max(total, 1)
          min_angle = math.radians(progress * 360 - 90)
          min_len = int(radius * 0.7)
          mx = int(cx + min_len * math.cos(min_angle))
          my = int(cy + min_len * math.sin(min_angle))
          cv2.arrowedLine(img, (cx, cy), (mx, my), color, 3, tipLength=0.2)

          # 초침 — 시간 기반 (60초 1회전)
          sec = timestamp % 60
          sec_angle = math.radians(sec * 6 - 90)     # 6° per second
          sec_len = int(radius * 0.9)
          sx = int(cx + sec_len * math.cos(sec_angle))
          sy = int(cy + sec_len * math.sin(sec_angle))
          cv2.arrowedLine(img, (cx, cy), (sx, sy), (0, 0, 255), 2, tipLength=0.15)

          # 중심점
          cv2.circle(img, (cx, cy), 5, color, -1)

  15.5 파일 생성 흐름
  ───────────────────

      def generate_test_frames(output_dir, count=100, width=2448, height=2048,
                               channels=3, fps=30.0, image_format="png",
                               session="S001", bg_color=(32,32,32),
                               text_color=(0,255,0)):

          now = datetime.now()
          base_dir = (Path(output_dir)
                      / f"{now.year}" / f"{now.month:02d}" / f"{now.day:02d}"
                      / session)
          base_dir.mkdir(parents=True, exist_ok=True)

          interval = 1.0 / fps
          base_ts = now.timestamp()
          ext = f".{image_format}"

          for i in range(1, count + 1):
              ts = base_ts + (i - 1) * interval
              dt = datetime.fromtimestamp(ts)
              ms = dt.microsecond // 1000

              # SaveImage 파일명 형식 (완벽히 동일)
              filename = (f"img_{i:04d}_{dt.strftime('%Y%m%d_%H%M%S')}"
                          f"_{ms:03d}{ext}")

              img = _render_frame(i, count, width, height, channels,
                                  ts, fps, bg_color, text_color)

              filepath = str(base_dir / filename)
              cv2.imwrite(filepath, img)

          # manifest.json (선택)
          manifest = {
              "session": session,
              "camera": "test_generator",
              "shape": [height, width, channels] if channels > 1
                       else [height, width],
              "format": image_format,
              "fps": fps,
              "count": count,
              "start_time": datetime.fromtimestamp(base_ts).isoformat(),
              "end_time": datetime.fromtimestamp(
                  base_ts + (count - 1) * interval).isoformat(),
          }
          import json
          with open(base_dir / "manifest.json", "w") as f:
              json.dump(manifest, f, indent=2)

          print(f"Generated {count} frames → {base_dir}")
          return str(base_dir)

  ├────┼─────────────────────────┼──────────────────────────────────────┤
  │ V3 │ fps 정확성               │ 시계 초침이 실시간과 동기 확인       │
  │    │                          │ 30fps → 초침 1초에 30프레임 이동    │
  ├────┼─────────────────────────┼──────────────────────────────────────┤
  │ V4 │ 타이밍 지연              │ TIME 표시와 현재 시각 차이 = 지연    │
  ├────┼─────────────────────────┼──────────────────────────────────────┤
  │ V5 │ 루프 경계                │ FRAME 번호 max → 1로 리셋 확인      │
  │    │                          │ 분침이 12시→12시 1회전              │
  ├────┼─────────────────────────┼──────────────────────────────────────┤
  │ V6 │ trigger/one_shot 동작    │ step 모드에서 번호 1씩 증가 확인    │
  │    │                          │ 시계 바늘 1스텝씩 전진              │
  ├────┼─────────────────────────┼──────────────────────────────────────┤
  │ V7 │ 이미지 저장 검증         │ saver 저장 파일의 FRAME 번호 확인   │
  │    │                          │ max_fps 제한 시 건너뛴 번호 확인    │
  └────┴─────────────────────────┴──────────────────────────────────────┘

  분침 = 전체 진행율, 초침 = 시간 기반이므로:
  - 분침이 멈추면: 재생 정지 상태
  - 초침만 움직이면: 실시간은 흐르나 프레임이 안 오는 상태 (병목)
  - 둘 다 부드럽게 회전: 정상 재생

  16. SimUI — 시뮬레이션 제어 UI 패널
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  SimCam 전용 제어 UI. SaveImageUI와 동일한 @task + QWidget 패턴.
  SimCam의 RMI를 호출하여 재생/정지/스텝/탐색을 제어하고,
  시그널을 수신하여 상태를 실시간 표시한다.

  16.1 목적
  ─────────

  - SimCam 재생 상태를 시각적으로 확인 (프레임 위치, fps, 모드)
  - Play/Pause/Step/Seek 조작으로 재생 흐름 제어
  - 세션 전환, 재생 모드 변경, 루프 설정을 UI에서 직접 수행
  - viewer/saver와 독립 — SimCam RMI만 사용

  │ 위젯               │ 동작                                            │
  ├────────────────────┼─────────────────────────────────────────────────┤
  │ Play 버튼          │ cam.trigger_mode = False                        │
  │                    │ → 자동 재생 시작/재개                            │

  │ Step 버튼          │ cam.one_shot()                                  │

  │ Session 콤보박스   │ cam.set_session(name)                            │
  │                    │ → 다른 세션으로 전환 (목록은 get_info()에서)     │
  ├────────────────────┼─────────────────────────────────────────────────┤
  │ Loop 토글          │ cam.loop = True/False                            │
  │                    │ ToggleSwitch (SaveImageUI 스타일)                │

  │ Trigger 토글       │ cam.trigger_mode = True/False                    │

  ├────────────────────┼─────────────────────────────────────────────────┤
  │ Speed 콤보박스     │ 0.25x / 0.5x / 1.0x / 2.0x / 4.0x              │
  │                    │ → cam.fps = base_fps * speed_multiplier         │
  │                    │ realtime 모드에서만 유효                         │
  ├────────────────────┼─────────────────────────────────────────────────┤
  │ Status 영역        │ 읽기 전용 라벨 — 시그널 수신으로 자동 갱신      │
  │                    │ State / Frame / FPS / Session / Drops / Loops   │
  └────────────────────┴─────────────────────────────────────────────────┘

  16.4 시그널 수신 (SimCam → SimUI)
  ─────────────────────────────────

  SimUI는 기존 camera.* 시그널을 그대로 수신한다 (코드 변경 0):

  ┌───────────────────────┬────────────────────────────────────────────┐
  │ 시그널                │ SimUI 처리                                  │
  ├───────────────────────┼────────────────────────────────────────────┤
  │ camera.connected      │ status = "CONNECTED"                       │
  │                       │ mode 표시 ("sim")                           │
  │                       │ fps 표시, UI 활성화                         │
  │                       │ get_info() → 총 프레임/세션 목록 갱신       │
  ├───────────────────────┼────────────────────────────────────────────┤
  │ camera.disconnected   │ status = "STOPPED"                         │
  │                       │ captured/dropped 최종 표시                  │
  │                       │ Transport 버튼 비활성화                     │
  ├───────────────────────┼────────────────────────────────────────────┤
  │ camera.received       │ rx_count → Seek 슬라이더 위치 갱신         │
  │                       │ rx_drop → Drops 카운트 갱신                │
  │                       │ Frame 라벨: "rx_count / total"             │
  │                       │ FPS 계산 (수신 간격 기반)                   │
  └───────────────────────┴────────────────────────────────────────────┘

  중요: camera.received는 고빈도이므로 UI 갱신 주기를 제한한다.
  _display_interval = 1/30 (30Hz) — viewer와 동일 패턴.

  16.5 RMI 호출 (SimUI → SimCam)
  ──────────────────────────────

  SimUI의 target은 config.json에서 "client:camera1"로 주입.
  기존 viewer가 사용하는 것과 동일한 RMI 프록시.

      self.target = None    # inject("client:camera1") — SimCam RMI

  ┌──────────────────────┬───────────────────────────────────────────┐
  │ UI 동작              │ RMI 호출                                   │
  ├──────────────────────┼───────────────────────────────────────────┤
  │ Play 클릭            │ self.target.trigger_mode = False           │
  │ Pause 클릭           │ self.target.trigger_mode = True            │
  │ Step 클릭            │ self.target.one_shot()                     │
  │ Stop 클릭            │ self.target.pause()                        │
  │ Seek 변경            │ self.target.seek(n)                        │
  │ Mode 변경            │ self.target.replay_mode = mode (*)         │
  │ FPS 변경             │ self.target.fps = value                    │
  │ Session 변경         │ self.target.set_session(name)              │
  │ Loop 토글            │ self.target.loop = value (*)               │
  │ Speed 변경           │ self.target.fps = base_fps * multiplier    │
  │ 초기화 (connected)   │ self.target.get_info()                     │
  └──────────────────────┴───────────────────────────────────────────┘

  (*) replay_mode, loop은 DEVICE_PROPERTY가 아닌 일반 config 속성이므로,
      SimCam에서 @rmi_task setter를 별도 제공해야 한다:

      @rmi_task
      def set_replay_mode(self, mode: str):
          self.replay_mode = mode

      @rmi_task
      def set_loop(self, value):
          self.loop = value

  16.6 버튼 상태 전환
  ───────────────────

  ┌──────────────┬──────┬───────┬──────┬──────┐
  │ 상태          │ Play │ Pause │ Step │ Stop │
  ├──────────────┼──────┼───────┼──────┼──────┤
  │ DISCONNECTED │  ✗   │  ✗    │  ✗   │  ✗   │
  │ PLAYING      │  ✗   │  ✓    │  ✗   │  ✓   │
  │ PAUSED       │  ✓   │  ✗    │  ✓   │  ✓   │
  │ STOPPED      │  ✓   │  ✗    │  ✗   │  ✗   │
  └──────────────┴──────┴───────┴──────┴──────┘

  DISCONNECTED = camera.disconnected 수신 또는 초기 상태
  PLAYING      = camera.connected 수신 + trigger_mode=False
  PAUSED       = trigger_mode=True (Play→Pause 또는 step 모드)
  STOPPED      = end_of_replay (마지막 프레임 도달, loop=false)

  Seek 슬라이더:
  - PAUSED 상태에서만 드래그 가능 (사용자 조작)
  - PLAYING 상태에서는 추적만 (rx_count 반영, 드래그 불가)

  16.7 클래스 설계
  ────────────────

      @task()
      class SimUI(QWidget):
          """SimCam 제어 UI 패널 (@task + QWidget)

          config.json 주입:
              target — inject("client:camera1") — SimCam RMI 프록시
          """

          def __init__(self):
              super().__init__()
              self.target = None
              self._state = "DISCONNECTED"
              self._total_frames = 0
              self._current_frame = 0
              self._base_fps = 30.0
              self._sessions = []

              # FPS 계산
              self._frame_count = 0
              self._last_fps_time = 0.0
              self._display_fps = 0.0
              self._last_display_time = 0.0
              self._display_interval = 1.0 / 30

              self._init_ui()

          def run(self):
              """초기화 — SimCam 미기동 시 RMI 호출 없음"""
              pass

          # ── 시그널 핸들러 ──────────────────────────────

          @ui_thread
          def on_camera_connected(self, signal):
              """SimCam 연결 → UI 활성화 + 정보 조회"""
              data = signal.data
              self._base_fps = data.get("fps", 30.0)
              self._state = "PLAYING"
              self._update_button_state()

              # 프레임 정보 조회
              if self.target:
                  try:
                      info = self.target.get_info()
                      self._total_frames = info.get("total", 0)
                      self._sessions = info.get("sessions", [])
                      self._update_seek_range()
                      self._update_session_combo()
                  except Exception:
                      pass

              self._update_status("PLAYING", data.get("mode", "sim"))

          @ui_thread
          def on_camera_disconnected(self, signal):
              """SimCam 종료 → UI 비활성화"""
              data = signal.data
              self._state = "STOPPED"
              self._update_button_state()
              self._update_status(
                  "STOPPED",
                  f"captured={data.get('captured', 0)} "
                  f"dropped={data.get('dropped', 0)}")

          def on_camera_received(self, signal):
              """프레임 수신 → 상태 갱신 (주기 제한)"""
              import time
              now = time.time()
              data = signal.data

              # FPS 카운터
              self._frame_count += 1
              if now - self._last_fps_time >= 1.0:
                  self._display_fps = self._frame_count / (
                      now - self._last_fps_time)
                  self._frame_count = 0
                  self._last_fps_time = now

              # UI 갱신 주기 제한
              if now - self._last_display_time < self._display_interval:
                  return
              self._last_display_time = now

              self._current_frame = data.get("rx_count", 0)
              rx_drop = data.get("rx_drop", 0)
              # → _frame_ready QtSignal로 UI 스레드 전달
              self._status_ready.emit(
                  self._current_frame, self._total_frames,
                  self._display_fps, rx_drop)

          # ── Transport 버튼 ────────────────────────────

          def _on_play(self):
              if not self.target:
                  return
              self.target.trigger_mode = False
              self._state = "PLAYING"
              self._update_button_state()

          def _on_pause(self):
              if not self.target:
                  return
              self.target.trigger_mode = True
              self._state = "PAUSED"
              self._update_button_state()

          def _on_step(self):
              if not self.target:
                  return
              self.target.one_shot()

          def _on_stop(self):
              if not self.target:
                  return
              self.target.pause()
              self._state = "STOPPED"
              self._update_button_state()

          # ── Seek ──────────────────────────────────────

          def _on_seek_changed(self, value):
              """슬라이더 드래그 → seek RMI (PAUSED만)"""
              if self._state != "PAUSED" or not self.target:
                  return
              self.target.seek(value)

          # ── Settings ──────────────────────────────────

          def _on_mode_changed(self, mode):
              if self.target:
                  self.target.set_replay_mode(mode)

          def _on_fps_changed(self, value):
              if self.target:
                  self.target.fps = value

          def _on_session_changed(self, name):
              if self.target:
                  self.target.set_session(name)

          def _on_loop_changed(self, checked):
              if self.target:
                  self.target.set_loop(checked)

          def _on_speed_changed(self, text):
              """Speed 배율 → fps 계산"""
              multiplier = float(text.replace("x", ""))
              if self.target:
                  self.target.fps = self._base_fps * multiplier

  16.10 SimUI ↔ Viewer 역할 분리
  ───────────────────────────────

  ┌───────────────────┬───────────────────────┬────────────────────────┐
  │ 기능              │ ImiCameraView (viewer)│ SimUI                  │
  ├───────────────────┼───────────────────────┼────────────────────────┤
  │ 이미지 표시       │ ✓ (SmBlock copy)      │ ✗ (이미지 없음)        │
  │ FPS 오버레이      │ ✓                     │ ✓ (텍스트만)           │
  │ trigger_mode 제어 │ ✓ (설정 다이얼로그)   │ ✓ (Play/Pause)         │
  │ exposure 제어     │ ✓ (슬라이더)          │ ✗ (SimCam 무의미)      │
  │ 재생 모드 변경    │ ✗                     │ ✓ (Mode 콤보)          │
  │ Seek/Step 제어    │ ✗                     │ ✓ (슬라이더 + 버튼)    │
  │ 세션 전환         │ ✗                     │ ✓ (Session 콤보)       │
  │ 루프 설정         │ ✗                     │ ✓ (Loop 토글)          │
  │ 재생 속도         │ ✗                     │ ✓ (Speed 콤보)         │
  │ smblock 필요      │ ✓                     │ ✗                      │
  └───────────────────┴───────────────────────┴────────────────────────┘

  viewer는 이미지 표시 전문, SimUI는 재생 제어 전문.
  두 위젯 모두 "client:camera1" 대상 → 동일 SimCam 인스턴스 제어.
  viewer의 설정 다이얼로그에서 trigger_mode를 바꾸면
  SimUI의 Play/Pause 상태도 시그널 기반으로 동기화된다.
